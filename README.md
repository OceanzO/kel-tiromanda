# Kelurahan Tiromanda — Portal Digital Resmi

Official Digital Portal of Kelurahan Tiromanda, Makale Selatan, Tana Toraja. Built with Next.js, TypeScript, Tailwind CSS, and Framer Motion.

## Getting Started

First, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
